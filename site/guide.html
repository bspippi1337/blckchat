Getting started

Development preview: GitHub room provisioning, SMS invitations and the guest gateway are planned, not operational. This guide describes the target experience.

Administrator

  1. Connect your GitHub account using an official OAuth login flow.
  2. Create a private room. The gateway provisions a private repository owned by the administrator.
  3. Invite a guest by entering their phone number. The gateway creates a single-use invitation, valid for a maximum of ten minutes, and sends an SMS through an SMS provider.
  4. Manage guest access and revoke sessions from room settings.

Guest

  1. Open the received HTTPS invite link on your device.
  2. Redeem the invite. The gateway validates expiry and one-time use.
  3. Choose a display name and enter the same shared conversation. No GitHub account is necessary.

What to expect

Message syncing uses a gateway and the GitHub API. Delivery is not guaranteed to be instantaneous. Offline clients will catch up after reconnecting when implemented.

Developer quick start

The current CLI works only on local files. It neither sends messages nor connects to GitHub:

make && make test
./blckchat init demo
./blckchat send demo alice "hello"
./blckchat read demo
make preview
